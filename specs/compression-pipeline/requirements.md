# Requirements: Extreme Generative Compression Pipeline

## User Stories
- As a user, I can upload an image or short sequence and receive a tiny seed.
- As a user, I can reconstruct a viewable version from the seed and compare it side-by-side with the original.
- As a user, I can see the actual compression ratio and a simple quality note.
- As a judge, I can understand the connection to the lost Sloot system and modern neural compression research.

## Acceptance Criteria
- Upload accepts common image formats.
- Seed is dramatically smaller than the source.
- Reconstruction is displayed side-by-side.
- Ratio and a perceptual note are shown.
- Historical context is visible in the UI.
- Works offline or with a lightweight model for demo reliability.
